Репозиторий apk для OpenWrtOpenWrt apk repository

OpenWrt 25.12, архитектура x86_64. Все пакеты подписаны ключомOpenWrt 25.12, architecture x86_64. All packages are signed with the key r4ven-apk.

ПодключениеSetup

wget -O /etc/apk/keys/r4ven-apk.pub https://apk.r4ven.me/r4ven-apk.pub
echo https://apk.r4ven.me/25.12/x86_64/packages.adb > /etc/apk/repositories.d/r4ven.list
apk update
apk add luci-app-ocserv-r4ven-me
